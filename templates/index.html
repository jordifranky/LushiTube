04 / AYUDA Preguntas frecuentes

Lo esencial, sin letra pequeña visual.

¿Necesito crear una cuenta?+

No. La interfaz no requiere registro para usar las herramientas disponibles en esta versión.

¿Qué puedo descargar?+

Utiliza LushiTube únicamente con contenido propio, de dominio público o para el que tengas permiso de descarga.

¿Qué pasa cuando termina una descarga?+

La interfaz muestra el estado completado y ofrece dos acciones claras: descargar de nuevo o iniciar una nueva descarga.
